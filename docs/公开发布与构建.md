# 公开发布与构建说明

本仓库是 BeatGlint 的 Phira 渲染器工作台。默认构建的是无 Tauri 的 `headless` 诊断渲染器，支持 PNG、单帧和 bounded segment；完整视频背景与完整 Phira 音频仍以原始 AppImage 为参考。仓库不提供谱面、音频、曲绘、皮肤、AppImage 或渲染视频，使用者必须自行准备有权使用的输入。

## 环境要求

- Linux、Rust stable（当前验证使用 Rust 1.99.1）；
- `ffmpeg`、`ffprobe`；
- 可用的 Xorg/Mesa 离屏显示；
- 一份输入 `.pez` 和一个资源目录，其中至少有 `font.ttf`、音效和皮肤。

项目验证使用隔离目录，避免修改用户现有 Rust 或 BeatGlint Python 环境：

```bash
export RUSTUP_HOME="$PWD/.rustup"
export CARGO_HOME="$PWD/.cargo"
export PATH="$CARGO_HOME/bin:$PATH"
```

## 构建和测试

```bash
cargo test --manifest-path upstream/headless-render/Cargo.toml
cargo check --manifest-path upstream/headless-render/Cargo.toml
cargo build --release --manifest-path upstream/headless-render/Cargo.toml
```

可选的性能对照构建：

```bash
cargo build --profile release-fast --manifest-path upstream/headless-render/Cargo.toml
```

`release-fast` 只用于和默认 release 比较 hash、帧数和时钟，不能未经验证替换默认构建。

## 时间窗口和运行

调用方先把 gameplay chart time 转换成 renderer video time。不要直接把官谱标注的 nominal chart 秒数传给 renderer，也不要在代码中写死 `+3.6`：

```bash
python tools/convert_chart_window.py \
  --start-chart-s 36.7 --end-chart-s 37.7 --fps 30 \
  --readback-lag-frames 2
```

headless bounded direct-readback 通常使用 `--readback-lag-frames 0`；原始 full AppImage 的历史 PBO 参考可能使用 2 帧。转换结果、renderer commit、二进制 SHA、输入 SHA 和输出 SHA 应一并写入 manifest。

渲染协议读取两行 JSON：第一行是 RenderParams，第二行是输出路径。实际命令还需把资源目录作为最后一个参数传入：

```bash
printf '%s\n%s\n' "$PARAMS_JSON" "$OUTPUT_JSON" | \
  ./upstream/headless-render/target/release/phira-render-headless \
  render /path/to/phira-assets
```

公开仓库不附带 Xorg 配置、谱面或资源。请使用本机的离屏显示配置，并确认输出只包含你有权分发的内容。

## 验证输出

```bash
python tools/verify_headless_smoke.py \
  /path/to/your/headless-smoke.json \
  --renderer-binary upstream/headless-render/target/release/phira-render-headless
```

已有两个渲染 artifact 时，可比较帧网格和逐帧 hash：

```bash
python tools/compare_render_artifacts.py \
  --left /path/to/release.mp4 --right /path/to/release-fast.mp4 \
  --manifest /path/to/your/headless-smoke.json \
  --case-index 3
```

这些检查只证明输出协议和 bounded replay 一致，不证明与官方 Phira 的视觉、粒子、视频背景或真人可玩性 parity。公开前请逐项完成 [`PUBLIC-RELEASE-CHECKLIST.md`](../PUBLIC-RELEASE-CHECKLIST.md)，尤其是 `prpr-avc` 许可证和锁定依赖 SBOM。
